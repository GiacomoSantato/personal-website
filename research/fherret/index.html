Fherret: Proving Correct and Circuit-Private FHE Evaluation

April 17, 2025 · Giacomo Santato

This note summarizes ongoing research on proving the correctness of homomorphic evaluation under malicious server behavior, without sacrificing circuit privacy — a known challenge in FHE deployment.

🔍 Motivation#

Most FHE schemes assume an honest-but-curious evaluator. But in practice, a malicious server may:

  • Deviate from the intended computation
  • Inject faults to manipulate results
  • Exploit client reactions via decryption or verification oracles

Existing integrity solutions often violate circuit privacy or require heavyweight cryptographic tools.

🦊 What is Fherret?#

Fherret is a custom proof system based on the MPC-in-the-Head (MPCitH) paradigm. It enables a server to prove to a client that the FHE evaluation was done correctly, without revealing any structural information about the circuit.

🧠 Core Idea#

  • The server simulates an MPC execution on a function from the allowed class
  • It proves (non-interactively) that the ciphertext matches the output of this simulation
  • All this happens without disclosing the function, maintaining circuit privacy

The proof is secure even when the client acts as a decryption or verification oracle.

📊 Performance Snapshot#

  • Prover: 4λ homomorphic evaluations of random functions
  • Verifier: 2λ homomorphic evaluations
  • Communication: O(√λ · |F|), where F is the function class
  • Naturally parallelizable for efficiency in practice

🤝 Applications#

Fherret contributes to building verifiable and private outsourced computation platforms using FHE. It’s particularly relevant for:

  • Secure FHE-as-a-service
  • Cloud-based encrypted ML
  • Proof-of-evaluation without trusted setup
